# Проявка — памятка для Claude

Свой графический редактор пользователя для iPad и ПК: фотобаш + нейросети, для кат-сцен
визуальных новелл (Senses). Написан с нуля, без фреймворков: весь редактор — один `index.html`
(обычный JS + canvas + WebGL2), без сборки. Правка → push в `main` → через пару минут новая
версия на https://itanaro.github.io/proyavka/ — и на айпаде, и на ПК.

## Начало каждого чата — по порядку

1. `git pull --ff-only` (бывают коммиты из других чатов).
2. `python3 tools/check.py` — сверка: версия в программе = `version.json` = последний коммит =
   `docs/STATE.md` = последняя запись `docs/log/`, и в публичных файлах нет личного. Если что-то
   не сходится — **сказать пользователю первым делом**: значит, прошлый чат не дописал запись.
3. Прочитать **`docs/STATE.md`** — где мы сейчас, что ждёт проверки, что дальше.
4. Прочитать **`docs/DECISIONS.md`** — решения и то, что отложено сознательно (не предлагать заново).
5. По задаче:
   - где что в коде — **`docs/MAP.md`** и `python3 tools/map.py слово`;
   - когда что сделано — `docs/HISTORY.md`, подробности — `docs/log/`
     (№1–108 — архив в проекте Claude: `claude/proyavka-log.md`, `claude/proyavka-log-2.md`,
     `claude/proyavka-log-3.md` — только чтение, их «памятки» устарели);
   - задача касается ПК, моста, туннеля, оболочки ПК — `claude/proyavka-private.md` в проекте
     (адреса, пути на ПК, детали связи; в репозиторий это не кладём);
   - задача касается плагина AI Edit или моста на ПК — ещё и общий журнал правок на ПК:
     `%APPDATA%\Adobe\UXP\Plugins\External\ЖУРНАЛ ПРАВОК.md` (дописывать строкой по его правилам).
6. Коротко сказать пользователю, на чём остановились (2–4 строки), и что показала сверка.

## Как работать с пользователем

- Она художник, не программист, но очень давно работает в Фотошопе и отлично знает его функции.
  Объяснять простыми словами, фотошопными терминами, без жаргона. Пишет по-русски.
- Спокойно, уважительно, по делу, без воды; можно подшучивать.
- Что можно сделать скриптом — делать самой, не перекладывать на неё.
- Когда чат разросся — сказать, что пора в новый, и **сразу дать готовую фразу для нового чата**:
  `Продолжаем Проявку.` (плюс одна строка о текущей задаче, если она не доделана).
  Остальное новый чат возьмёт отсюда.

## Правила работы

- **Обе версии — iPad и ПК — должны работать.** ПК ведёт себя как Фотошоп (клавиши, курсоры,
  поведение) и говорит по-компьютерному (тексты пишем как обычно, кривые фразы — в `DESK_PHRASES`).
- **Не двигать элементы интерфейса без просьбы.** Добавлять новые можно.
- **Код плагина AI Edit не трогать** — только обвязку Проявки (подмена API Фотошопа, стили окна).
- Баги из её тестов — чинить сразу, отдельной версией.
- Новые элементы красить только переменными темы (`--accent`, `--fg`, `--muted`, `--soft*`,
  `--line*`, `--field`, `--ai`, `--glass-*`), иначе выпадут в светлых темах. Фон вокруг холста
  (`BG`) — отдельная настройка, от темы не зависит.
- Сквозные правила кода (новый тип слоя, отмена, смарт-объекты, окна, айпад) — в `docs/MAP.md`,
  раздел «Сквозные правила».

## Выпуск версии — всё одним коммитом

Запись о правке уходит **в том же коммите**, что и код. Тогда журнал физически не может отстать.

1. Правка кода + проверка: `python3 tests/run.py` — все экраны зелёные (раздел «Тест»).
   Новая функция — новый шаг в `tests/smoke.js`.
2. В конец `docs/log/from-109.md` (или последнего файла `docs/log/`) — запись `## №NNN — …`
   по шаблону в начале файла.
3. **Переписать** `docs/STATE.md`: версия, последнее сделанное, обновлённый список «Проверить
   вживую», «Дальше».
4. Одна строка в `docs/HISTORY.md`. Новое решение пользователя — строкой в `docs/DECISIONS.md`.
   Новый раздел кода — строкой в `docs/MAP.md`.
5. `python3 tools/release.py NNN "что сделано коротко"` — ставит `APP_VERSION` и `version.json`
   одинаково (дата по Москве), проверяет записи, запускает `tools/check.py`.
6. `git add -A && git commit -m "№NNN: …" && git push`. Номера идут подряд.

Пользователь увидит плашку «Есть новая версия». Если `sw.js` должен кэшировать новый файл —
поднять номер кэша `proyavka-shell-vNN`.

Изменения без новой версии редактора (только доки, мост, оболочка ПК) — коммит без номера,
но запись в журнал всё равно (раздел без номера, как «Система передачи» 24.10).

## Тест

- **`python3 tests/run.py`** — автотесты одной командой: сам поднимает сайт и заглушку нейросетей,
  гоняет до 20 шагов на каждом из 4 экранов (ПК 1920 и 1366, iPad альбом и портрет; каждый в своей теме),
  печатает ✓ / ✗. Перед выпуском — все экраны; по ходу — `python3 tests/run.py pc1920` или
  `--only слово`. Подробно и как добавить шаг — `tests/README.md`.
- Разовые проверки сверх набора — Playwright из scratchpad (`NODE_PATH=/opt/node22/lib/node_modules`),
  сервер `python3 -m http.server 8766` в папке репозитория (в той же команде, что и тест), заглушка
  `python3 tests/stub.py`. WebGL2: `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`.
- Chromium без UA айпада = ПК-версия (`IS_DESK`); с UA iPad + `hasTouch` = айпад.
- До загрузки (`addInitScript`): `localStorage kadr.help='1'` (иначе справка перекрывает холст).
  Перезагрузку страницы — не раньше 6 с после старта (иначе защита от падения откроет «Начало»).
  Касания — на холст `#ovl`, не на `#stage` (Проявка берёт только их).
- Скрипты и скриншоты разовых проверок — только в scratchpad, не в папку репозитория.
  `rm *.png` в репозитории не делать: там есть нужные png.

## ПК пользователя (общее; адреса и пути — в `claude/proyavka-private.md`)

- Windows, RTX 4090. Связь — через «привязку к компьютеру» в приложении Claude.
- Мост (`pc-bridge/bridge.py`, копия в репозитории) на ПК класть файлом целиком — мост сам
  перезапускается при изменении своих файлов.
- **Содержимое** батников — только ASCII (cmd ломает кириллицу); имя файла может быть русским.
  Строки туннеля (`HTTPS_PROXY` / `HTTP_PROXY` / `NO_PROXY`) в батниках моста сохранять — какие
  именно батники их содержат, сказано в `claude/proyavka-private.md`.
- Копия моста в репозитории (`pc-bridge/`) может отставать от файла на ПК. Перед правкой —
  сравнить оба (`device_bash`: хэш или diff), править свежий, после правки положить его и на ПК,
  и в `pc-bridge/` (без ключей и сертификатов).
- Удалять файлы на ПК нельзя без прямой просьбы.
- Не открывать через `device_list_dir` папки Electron-приложений с `.asar` — файл блокируется,
  пока не выйдешь из Claude. Там — только `device_bash`.

## Безопасность и открытый репозиторий

- Ключи API живут только на устройствах пользователя — не просить вставлять в чат, не печатать.
  `team-config.json` (плагин) не печатать — там ключи. `rootCA.key` никому не отдавать.
- **Репозиторий сейчас открытый** (станет закрытым позже). В коде, журнале и доках — никаких
  адресов, почты, путей с именем пользователя, деталей туннеля и личного. Такое — в
  `claude/proyavka-private.md` в проекте. `tools/check.py` ищет типичные утечки.
