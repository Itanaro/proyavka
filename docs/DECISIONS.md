# Решения и принципы

Что решено и почему — чтобы новый чат не предлагал заново то, от чего уже отказались.
Меняется редко. Новое решение пользователя — дописать строкой в нужный раздел с датой.

## Для чего Проявка
- Редактор для ИИ-художника, который делает кат-сцены визуальных новелл (Senses). В первую очередь
  фотобаш и коллаж: выделения, маски, слои, трансформ, подгонка, ретушь — и нейросети. Рисованию
  кистью — меньше внимания.
- Две версии из одного кода: **iPad** (главный инструмент в дороге) и **ПК** (своё окно, как
  Фотошоп; в перспективе должна его заменить). Каждая правка — в обе.
- Цвет (25.10): Проявка работает только в sRGB, переключателя пространств нет; в сохранение вшивается sRGB, PSD с чужим
  профилем при открытии переводится в sRGB по согласию. Полноценная работа в Adobe RGB / P3 не нужна для катов.
- Ретушь кожи делается через Stable Diffusion, поэтому частотное разложение не нужно (может быть,
  сильно позже).

## Как должна ощущаться
- **ПК ведёт себя как Фотошоп**: те же клавиши (по физической клавише, в любой раскладке), курсоры,
  поведение меню, слоёв, выделений. Переход между ФШ и Проявкой — без трения. Говорит
  по-компьютерному (клик, мышь), а не «тап» (`DESK_PHRASES`).
- **iPad**: жесты как в Procreate, точные действия — пером, силу эффектов дозирует нажим (отдельных
  ползунков «нажима» нет). Всё нужное — рядом с местом работы, а не через весь экран.
- Инструменты ретуши, тона, коррекций, масок — ориентир Фотошоп.
- **Расположение элементов не менять без просьбы.** Добавлять новое можно.
- Внешний вид: «хорошенький, вкусный» — изящный, воздушный, скруглённый, стеклянные плавающие
  панели, один акцент. С №88 — темы серии (Ночь по умолчанию, Облачко, Луч, Графит); фон вокруг
  холста — отдельная настройка, от темы не зависит.
- Частые инструменты (удаление кистью) работают тихо: без затемнения экрана и плашек на каждое
  применение; подсказка при выборе инструмента — один раз (25.10).
- Глаз должен сразу схватывать, что где: значки, а не только подписи. Подписи в окнах короткие,
  длинные пояснения — под «?».
- Пользователь приветствует идеи «как сделать лучше» и охотно берёт их пачкой — но в рискованных
  вопросах (данные, аккаунты, обход правил) выбирает осторожный путь и готова подождать.

## Гаджеты рабочего места (с 24.10.2026)
- Едут очки XREAL One Pro и робот Loona Deskmate (мозг — её айфон; для ПК есть программа-прослойка, для разработчиков — OpenClaw, REST API). Оба должны органично работать с Проявкой и на ПК, и на айпаде; **без гаджетов у любого пользователя ничего не меняется** — всё включается, только если устройство есть.
- Очки за ПК — **дополнительный экран к экраннику**, не замена ему: рисует на экраннике, в очках — картина целиком, рефы, проверки. Айпад с очками — зеркало + курсор пера над экраном (iPad Pro M4/M5 13").
- Цвет в очках не эталон — сверять на основном экране.
- Робот: события Проявки (готово, ошибка, сдано, давно не сохраняла) и голосовые команды; подключать по настоящему API после доставки.

## Данные пользователя
- Работа не должна пропадать. Советы, которые могут стереть данные, — только после проверки и с
  резервной копией.
- **iPad:** ярлык на «Домой», вкладка Safari и будущее приложение — три разных хранилища. Удаление
  ярлыка стирает документы и модели (так уже случилось 1 октября). **Никогда не советовать удалять
  ярлык без «Файл → Резервная копия».**
- Ключи API живут только на устройствах пользователя (localStorage). В чат не просить, не печатать.
- Документы хранятся на устройстве (IndexedDB) и никуда не отправляются.

## Где работают нейросети
- Облако — основное для генерации (OpenRouter, Google AI Studio; fal.ai — запасной). ComfyUI на ПК
  для генерации не используем.
- Всё тяжёлое, что может уронить Safari, — на ПК через мост (выделение объекта BiRefNet, удаление
  фона, MI-GAN, глубина, SD Inpaint, ИИ-апскейл). Без моста — облегчённые сети на айпаде.
- Айпад ходит в облако через ПК и его VPN, когда ПК доступен (№57), из любой сети — через
  Tailscale (№58).
- Модели: для правки по рефу основная — Nano Banana 2.1 (смелее, держит кадр после №72–73);
  Seedream 5 Pro консервативен и умеет только до 2K. Тень объекта по карте глубины — убрана из
  плана: тень лучше руками.

## AI Edit (плагин Фотошопа)
- Один источник: Проявка не хранит копию плагина, а грузит его с диска ПК через мост и подменяет
  API Фотошопа. Правка плагина сразу работает и в ФШ, и в Проявке.
- **Код плагина правит только чат плагина.** Здесь — только обвязка (подмена API `AEHOST`, стили
  окна). Новые команды Фотошопа, которые завёл плагин, чат плагина пишет в общий
  `ЖУРНАЛ ПРАВОК.md` на ПК — их надо добавить в подмену.
- Инструмент «Доводка» (бывшая «Деталь») — одно название и в Проявке, и в плагине.
- На айпаде SD-ретушь — кнопкой Островка (третья по умолчанию); Островок настраивается сам: значки, 1–6 кнопок (25.10).
- Двигать холст пером (25.10): без скачков масштаба — «Обзор» (отдалить/приблизить) укачивает; основное — Навигатор и «Рука» на Островке.
- SD-ретушь кожи (25.10): F2 в Проявке = F2 в Фотошопе (команда плагина SD Inpaint). Настройки зашиты те же, промпт
  и негатив Проявка берёт из хранилища плагина через мост — один источник, отдельного промпта в Проявке не заводим.

## Стандарт ката Senses (для «Сдать кат», безопасной зоны)
- Рабочий размер **1500×2000** (3:4), 300 ppi (25.10: 3000×4000 обсуждали, но фактически не нужно).
  Сдача: PSD + PNG 1500×2000.
- Безопасная зона — 900 px при ширине 1500, то есть 60 % ширины по центру.
- Персонажи и фон — отдельными подписанными слоями. **Папку с цветокоррекцией не сдают** (25.10, после
  созвона с лидами): перед сдачей коррекцию применяют к фону и к слоям с персонажами.

## Отложено сознательно (не предлагать, пока пользователь не вернётся к теме)
- **Учётные записи и синхронизация через Google** (вход Google, файлы в Google Диске). Схема
  обсуждена 19.10 (журнал №87 и «Решение по учётным записям» в архиве). Вернуться, когда
  пользователь скажет, что готова дать первый тестовый доступ коллеге — и напомнить ей об этом.
  Первый доступ — одному человеку, не всей команде.
- Синхронизация ПК ↔ iPad (свой сервер) — после аккаунтов.
- Своё приложение для iPad через TestFlight — заготовка в `ios/`, выпуск отложен.
- Смарт-объекты: «Открыть содержимое», смарт-фильтры, деформация/перспектива смарта.
