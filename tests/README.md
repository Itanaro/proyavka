# Автотесты Проявки

```
python3 tests/run.py                  # все 4 экрана, ~4 минуты
python3 tests/run.py pc1920           # один экран: pc1920, pc1366, ipadL, ipadP
python3 tests/run.py --only смарт     # только шаги, где в названии есть «смарт»
```

Скрипт сам поднимает сайт из этой папки (`http://127.0.0.1:8766`) и заглушку нейросетей
(`tests/stub.py`, `:8199`), гоняет `tests/smoke.js` в Chromium и печатает ✓ / ✗ по каждому шагу.
Отчёт `report.json` и скриншоты (итог каждого экрана + кадр каждого провала) — во временной
папке вне репозитория (путь печатается в конце, свой — `--out`).

## Когда запускать
- **Перед каждым выпуском версии** — все экраны. Красное — не выпускать, пока не разберёшься.
- По ходу работы — нужный экран или `--only` по теме правки.

## Что внутри
- `run.py` — запуск серверов и прогона.
- `stub.py` — заглушка OpenRouter: картинки (отдаёт присланную, подкрашенную), арт-директор,
  модели, проверка ключа. Журнал запросов — `GET /_log` (тест проверяет, что ушло в модель),
  сброс — `POST /_reset`. Подсказка со словом `REFCOPY` — заглушка отдаёт второй реф
  (изображает модель, вернувшую кадр рефа).
- `lib.js` — экраны (ПК — обычный Chromium, iPad — UA айпада + касания), шаги, сбор ошибок
  страницы, отчёт. Хелперы: `penDrag` (перо, синтетические события на холст `#ovl` — одинаково
  на ПК и iPad), `mouseDrag` (настоящая мышь, только ПК), `until`, `check`.
- `smoke.js` — сами шаги. Любая ошибка в консоли страницы во время шага — шаг красный
  (кроме отказа соединения с мостом: его на тестовой машине нет).

## Как добавить шаг (каждая новая функция редактора)
В массив `steps` в `smoke.js`:

```js
{ name: 'Что проверяем', run: async page => {
    await page.evaluate(() => /* вызвать функцию Проявки или нажать кнопку */);
    check(await page.evaluate(() => /* условие */), 'что не так — понятными словами');
}},
```

`desk: true` — только ПК, `desk: false` — только iPad, `always: true` — выполнять и при `--only`.
Функции и переменные Проявки (`doc`, `S`, `AL()`, `undo()`…) доступны в `page.evaluate` напрямую.
Шаги идут по порядку в одном документе 1200×1600 — после себя возвращать как было (отмена).

## Чего здесь нет (проверять руками или отдельным тестом)
- Нейросети на устройстве и на ПК (глубина, тап по объекту, удаление, выделение объекта) —
  тяжёлые модели, в шаге «Все инструменты» эти инструменты пропускаются.
- Мост, SD Inpaint, AI Edit — нужен ПК пользователя.
- Настоящее перо айпада и Safari (WebKit в песочнице не ставится) — проверяет пользователь.
